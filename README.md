# Yantra Robotics

A modular, extensible robotics platform where software defines hardware behavior.

## Vision
People want robots that adapt to their life. Not robots built for one single purpose.
Yantra is the platform that makes that possible.

## Structure
- /docs — vision, learning log, build log
- /src — source code
- /hardware — schematics, specs, component notes

## Status
Early exploration. ROS2 foundation in progress.
